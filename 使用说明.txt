CODM Tune v10 使用说明
======================

1. 启动
   双击 codmtune.exe（或桌面 CODM Tune 快捷方式）。首次启动会在工作区居中；配置、日志、知识库写入
   %APPDATA%\CODMTune（便携测试可用 CODMTUNE_HOME 指定目录）。
   如果窗口已隐藏到托盘，再次双击会唤起原窗口，不会重复开进程；如果窗口本来可见，
   会弹出一条“已经在运行”的顶层提示。

2. 默认外观
   默认是「舟味 · 工业终端」浅色纸灰 + 红色强调色。
   设置 → 界面风格 可切标准 MD3E；设置 → 主题 可在纸灰、墨黑、OLED 间切换。
   强调色可选蓝/薄荷/琥珀/紫/红，也可从壁纸取色或输入 #RRGGBB。
   舟味与标准都支持浅色/深色；高级模式会强制危险红并播放扫描动画。

3. 键盘
   ↑/↓ 在内容区移动；←/→ 调二级值；Enter 展开/执行；Esc 返回；F11 进入/退出
   FIELD TERMINAL 全屏终端；滚轮滚动列表。内容区第一行继续向上不会再跳到侧栏。
   舟味分类切换约 0.78 s，ease-out 斜切；只绘制新页，不应掉帧。

4. 悬浮窗
   设置 → 悬浮窗：启用、未进游戏也显示、样式（紧凑/完整/纯文字）、四角位置、
   透明度（140–255）；可分别关闭 FPS、1% low、卡顿、吞子弹、按键、网络/省份。
   纯文字模式不画卡片底，适合叠在游戏画面上。FPS 依赖 PresentMon/ETW，本机
   如果拿不到 Present 事件会显示 N/A，这是真实结果，不是占位符。

5. 扫描
   诊断页的显卡/网络扫描是异步的：行内会显示“扫描中 xx%”，完成后同一页原地
   出现结果，不需要退出重进。

6. 全屏终端
   F11 进入 1920×1080 无边框终端，先出底色再从左向右揭开，约 0.72 s；F11 返回。
   终端只读，不参与主界面命中测试。

7. 安全边界
   不注入 DLL、不 WriteProcessMemory、不 CreateRemoteThread、不 SetWindowsHookEx；
   不结束/挂起 ACE；不修改游戏目录文件；注册表写前保存原值。
   HKLM/系统项只在高级模式出现；电源切换会保留熄屏/休眠超时。

8. 常见问题
   - Explorer 大图标仍旧：先确认快捷方式指向新的 exe（本版为纸灰底黑枪 + 红切角）。
     若仍显示旧红底白枪，注销/重启资源管理器或清图标缓存后再看；exe 内已写入
     16/20/24/32/40/48/64/96/128/256 十档。
   - 独占全屏看不到 HUD：layered 子进程在真独占全屏下可能被遮挡，先切无边框。
   - 扫描没有结果：等进度到 100%；仍失败请导出诊断 txt。

9. 构建
   set GOPATH=E:\GoPath
   set GOMODCACHE=E:\GoPath\pkg\mod
   set GOPROXY=https://goproxy.cn,direct
   build.cmd
   go vet ./...
   go test ./...

反馈请附「诊断 → 导出诊断报告」生成的 txt（不含凭证）。
